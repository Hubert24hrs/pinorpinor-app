# Pinorpinor Mobile — agent instructions

**Read [`CLAUDE.md`](CLAUDE.md). It is the only project memory for this
repository.**

This file exists because some tools look for `AGENTS.md` by convention. It
deliberately holds no facts of its own.

It used to hold a *copy* of `CLAUDE.md`, and the copy went stale: it was last
updated 2026-08-25 and still claimed 403 passing tests and a clean tree, while
`CLAUDE.md` had moved on to 422 and had recorded, among other things, that
every abuse report the app ever filed was being stored as "other". An agent
that happened to read this file instead of that one would have started from
facts that were two months out of date, and nothing here would have told it so.

Two files describing one codebase drift silently, which is the same failure
this repository already documents between the app and the website. One file.
